# MACAN Almaty

Static bilingual landing page for the MACAN clothing store in Almaty.

- Russian: `/`
- Kazakh: `/kz/`
- No build step or environment variables are required.

The page includes local business structured data, map links, and a `robots.txt` file. Add the production domain to canonical and `hreflang` metadata and publish a sitemap after the Vercel project URL is assigned.
